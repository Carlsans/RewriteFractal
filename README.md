# RewriteFractal

Escape-time fractals whose formula is generated by a **string-rewriting system**, searched with a genetic algorithm and
scored by how poorly the picture compresses.

- How it works, what worked and what did not: [docs/PROJECT.md](docs/PROJECT.md)
- Features that were tried and dropped: [docs/UNUSED_FEATURES.md](docs/UNUSED_FEATURES.md)

## GUI

```
pip install -r requirements-gui.txt
python -m gui.app
```

Tabs: **Explore** (edit start string, rules and constants, render, open and save genomes), **Gallery** (browse a folder of genomes),
**Evolve** (genetic algorithm with the active and legacy fitness functions), **Legacy / experimental** (compare all fitness functions, random miner,
variations, Optuna study, batch upscale).

`examples/` holds five genomes: open one with *Open .json*. A CUDA GPU is recommended. Genome `.json` files created on a GPU contain CUDA tensors
and need CUDA to load.

## Original scripts

`src/GeneticAlgorithm.py` is the original entry point. It needs the packages in `src/` imports (DEAP, Optuna, scikit-*) and trained autoencoder weights, which are not
in this repository. Set `GAOPTUNA_STORAGE` to your Optuna storage URL (default: a local SQLite file).

## Launch the GUI

Linux: `./run.sh`  
Windows: `run_win.bat`

The first run creates a `.venv` and installs `requirements-gui.txt`; later runs start immediately.
